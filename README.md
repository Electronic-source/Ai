# AI App v0.2.0

Android native Kotlin/Jetpack Compose scaffold for an AI chat + coding + GitHub app.

## Added in v0.2.0

- Files workspace tab
- Create text/code files from the app
- Add files to an in-app project workspace
- Build a real `.zip` archive from workspace files
- Export generated files and ZIP archives using Android Storage Access Framework / system File Picker
- No broad storage permission is required for normal export flows
